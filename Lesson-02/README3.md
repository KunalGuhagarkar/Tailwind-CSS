# Animated Mobile Menu & Hamburger Icon

A responsive single-page marketing site for the fictional **🚀 Acme Rockets**, built with semantic HTML, [Tailwind CSS v4](https://tailwindcss.com/), and a small amount of vanilla JavaScript. This iteration adds a full-screen mobile menu that drops down with a springy animation, and a CSS-only hamburger icon that morphs into an "X" when the menu is open. The site also includes a hero, rocket showcase, testimonials, a contact form, and a footer, with light and dark mode support.

## How the Mobile Menu Works

### Toggle logic (`main.js`)

On `DOMContentLoaded`, `initApp()` grabs `#hamburger-button` and `#mobile-menu`. Clicking either one runs `toggleMenu()`, which:

1. toggles `hidden` / `flex` on the menu so it appears or disappears
2. toggles the custom `toggle-btn` class on the hamburger button to trigger the icon animation

Because the menu itself also has the click listener, tapping any link in the overlay closes the menu as the page scrolls to the section.

### Slide-down animation

`input.css` defines an `open-menu` keyframe animation registered as `--animate-open-menu` in `@theme`, which Tailwind exposes as the `animate-open-menu` utility. The menu scales vertically from `0` to `1.2` (a slight overshoot) and settles at `1`, using `origin-top` so it appears to drop down from the header.

### Hamburger to X icon

The icon is built from a single `<div>` (the middle bar) plus its `::before` and `::after` pseudo-elements (top and bottom bars), all styled with Tailwind utilities and `transition-all duration-500`. The `toggle-btn` utility in `input.css` uses `@apply` with child selectors so that, when active:

- the top and bottom bars slide to the center (`translate-y-0`) and rotate `45deg` / `-45deg` to form an X
- the middle bar becomes transparent and spins (`rotate-720`)

## Tailwind Setup (v4, CSS-first)

All custom Tailwind configuration lives in `input.css`, so there is no `tailwind.config.js`:

```css
@import "tailwindcss";

@utility section-min-height {
    min-height: calc(100vh - 68px);
}

@custom-variant widescreen (@media (min-aspect-ratio: 3/2));
@custom-variant tallscreen (@media (max-aspect-ratio: 13/20));

@theme {
    @keyframes open-menu {
        0%   { transform: scaleY(0); }
        80%  { transform: scaleY(1.2); }
        100% { transform: scaleY(1); }
    }
    --animate-open-menu: open-menu 0.5s ease-in-out forwards;
}

@utility toggle-btn {
    @apply [&>div::before]:translate-y-0 [&>div::before]:rotate-45
           [&>div::after]:translate-y-0 [&>div::after]:-rotate-45
           [&>div]:bg-transparent [&>div]:rotate-720;
}
```

- **`section-min-height`**: at least one viewport tall, minus 68px for the sticky header
- **`widescreen:`**: viewport aspect ratio is 3:2 or wider
- **`tallscreen:`**: viewport aspect ratio is 13:20 or taller (narrow portrait screens)
- **`animate-open-menu`**: the drop-down animation for the mobile menu
- **`toggle-btn`**: the hamburger-to-X state

## Concepts Demonstrated

- **Custom animations** with `@theme` and `@keyframes` in Tailwind v4
- **Custom utilities** with `@utility` and `@apply`, including arbitrary child selectors (`[&>div::before]:`)
- **Pseudo-elements** (`before:` / `after:`) for both the hamburger bars and the testimonial quotation marks
- **Pseudo-classes** (`hover:`, `active:`): nav link hover, submit button states
- **DOM manipulation**: toggling classes with `classList.toggle`
- **Forms**: `<label for>`, `required`, `minlength`, `maxlength`, placeholders
- **Semantic HTML**: `<header>`, `<main>`, `<footer>`, `<address>`, `<figure>`, `<blockquote>`, labeled `<nav>` landmarks
- **Responsive design**: `sm:` / `md:` breakpoints (desktop nav and hamburger swap at `md`), aspect-ratio variants
- **Dark mode**: `dark:` variants throughout

## Getting Started

1. **Install Tailwind v4 and its CLI:**
   ```bash
   npm install tailwindcss @tailwindcss/cli
   ```
2. **Build the CSS:**
   ```bash
   npx @tailwindcss/cli -i ./input.css -o ./output.css --watch
   ```
3. **Add images** to `images/`, then open `index.html` in a browser or serve it:
   ```bash
   npx serve .
   ```
