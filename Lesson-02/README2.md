# Pseudo-Classes, Forms & Footer

A responsive single-page marketing site for the fictional **🚀 Acme Rockets**, built with semantic HTML and [Tailwind CSS v4](https://tailwindcss.com/). This iteration builds on the earlier layout by adding a testimonials section styled with pseudo-elements, a contact form, and a footer. Light and dark modes are both supported.

## Project Structure

```
.
├── index.html      # Main page
├── input.css       # Tailwind v4 source (custom utility + variants)
├── output.css      # Compiled CSS (linked from the <head>, generated by the build)
└── images/
    ├── rocketdab.png
    ├── rocketman.png
    ├── rocketride.png
    └── rocketlaunch.png
```

> `images/` is referenced by the page but not included here. Add your own or adjust the paths. `output.css` is generated by the build step below.

## Tailwind Setup (v4, CSS-first)

This project uses Tailwind v4's CSS-based configuration, so there is no `tailwind.config.js`. Everything custom lives in `input.css`:

```css
@import "tailwindcss";

@utility section-min-height {
  min-height: calc(100vh - 68px);
}

@custom-variant widescreen (@media (min-aspect-ratio: 3/2));
@custom-variant tallscreen (@media (max-aspect-ratio: 1/1));
```

- **`section-min-height`**: makes a section at least one viewport tall, minus 68px for the sticky header
- **`widescreen:`**: applies when the viewport aspect ratio is 3:2 or wider
- **`tallscreen:`**: applies when the viewport aspect ratio is 1:1 or taller (portrait or square)

The page uses these together (`widescreen:section-min-height tallscreen:section-min-height`) so each section fills the screen on very wide or very tall viewports, while standard-ratio screens keep natural content height.

## Concepts Demonstrated

- **Pseudo-elements** (`before:` / `after:`): decorative oversized curly quotation marks on each testimonial, positioned absolutely with opacity and translate utilities
- **Pseudo-classes** (`hover:`, `active:`, `focus:`): nav link hover, submit button hover/active states, and focus styling on the mobile menu button
- **Forms**: `<label for>` paired with inputs, plus built-in validation (`required`, `minlength="3"`, `maxlength="60"`) and placeholders
- **Semantic HTML**: `<header>`, `<main>`, `<footer>`, `<address>`, `<figure>`, `<blockquote>`, `<figcaption>`, and labeled `<nav>` landmarks
- **Responsive design**: `sm:` and `md:` breakpoints; price symbols on desktop swap to taglines on mobile
- **Dark mode**: `dark:` variants throughout
- **Scroll offsets**: `scroll-mt-*` so sticky-header anchors don't cover section headings
- **Custom variants and utilities**: aspect-ratio-based `widescreen:` / `tallscreen:` variants and the `section-min-height` utility (see above)

## Getting Started

1. **Install Tailwind v4 and its CLI:**
   ```bash
   npm install tailwindcss @tailwindcss/cli
   ```
2. **Build the CSS:**
   ```bash
   npx @tailwindcss/cli -i ./input.css -o ./output.css --watch
   ```
3. **Add images** to `images/`, then open `index.html` in a browser or serve it:
   ```bash
   npx serve .
   ```
